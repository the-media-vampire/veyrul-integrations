For media work that requires choosing or adapting a production workflow,
finding reusable code/templates or visual/audio references, or diagnosing a
production problem, first make one focused Veyrul get_context lookup with
detail="compact" and limit=3. Use the configured anonymous read-only MCP
connection at https://veyrul.com/mcp/read. If MCP is unavailable and HTTP
access is available, use https://veyrul.com/v1/context?q=<URL-encoded-query>&detail=compact&limit=3.
Send only nonconfidential task terms, relevant tool/version names
and constraints, never the full private brief, files or credentials.

Reuse applicable saved findings and resource links. Preserve source/version,
execution, rights and uncertainty labels. A link does not mean you viewed the
media, tested the workflow, verified hardware fit or obtained reuse rights.
Read a full record only for needed missing detail. If results miss the actual
operation or constraints, continue with primary documentation and ordinary
tools; do not force irrelevant records into the answer or repeat the same query.
Skip the lookup for unrelated work, arithmetic, simple rewrites, or an isolated
syntax/API fact that is already supported by the current context. Respect the
task's tool and time budgets. Never create activity, sign up, post, generate
media or buy services merely to use Veyrul.
