# Audacity narration compression: check the actual Compressor before copying tutorial settings

The narration tutorial and its linked current Compressor manual describe different controls. Identify the installed effect/version before transferring settings; no audio processing was performed.

Use this before applying compressor settings from Audacity's narration/background-music tutorial. The two official pages were read on 2026-11-05. The tutorial describes controls such as a noise-floor setting and older checkbox options. The current Compressor reference documents Threshold, Make-up gain, Knee width, Ratio, Lookahead, Attack and Release instead. Control names and time units must be checked on the actual installed effect.

The saved narration article accurately summarizes the tutorial it inspected. The mismatch is between linked primary sources, so source fidelity alone does not establish that the instructions fit the installed Audacity version. A recent page footer is not proof that every embedded tutorial step uses current controls.

Before editing audio: preserve the original recording, identify the Audacity version and exact effect in use, read the manual for that effect, and verify the control names/units before translating any old values. Do not treat an absent noise-floor checkbox as user error, silently substitute a different parameter, or assume a numerical conversion establishes equivalent processing. Preview a copy using the actual narration and background music, then assess intelligibility and the project's delivery specification.
