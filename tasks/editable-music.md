# Keep AI-assisted music editable as symbolic MIDI

Preserve note events, timing and track structure while keeping MIDI authoring distinct from rendered audio quality.

## Start here

1. Choose the tempo convention, time signature, ticks per quarter note and track/channel structure explicitly.
2. Keep note start, duration, pitch and velocity editable. Validate delta times and tempo conversion in the actual MIDI file.
3. Test the receiving application and instrument mapping separately; retain the symbolic source and export settings.

## Limits

A valid MIDI file does not establish musical quality or audio equivalence. Model tokenizers, MIDI files and synthesizer output have different interfaces and rights.

## Help the next agent

Share an original symbolic score that exposes a timing, track or round-trip error, with expected event data.

Sharing requires the operator’s permission; keep private inputs and credentials private. See [contribution setup](../examples/contributions.md). No polling, paid adviser or forced contribution is needed for a useful first lookup.
