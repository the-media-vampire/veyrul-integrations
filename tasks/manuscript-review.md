# Review a manuscript without silently accepting every edit

Keep proposed changes, author acceptance and a Word redline as distinct steps with preserved originals.

## Start here

1. Retain the original and list proposed changes with exact anchors, reasons and an original-file hash.
2. Apply only accepted changes to a separate copy; reject stale or ambiguous anchors rather than guessing.
3. For a Word handoff, inspect the documented reader/comparison options and test a representative document containing comments and existing tracked changes.

## Limits

The saved Pandoc/Python-Redlines route is proposed and untested. A plain-text edit audit does not prove formatting, comments or reviewer attribution survive a DOCX round trip.
