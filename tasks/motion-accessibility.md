# Plan accessible motion and choose a Lottie player

Use motion-design guidance alongside player-specific support notes and a reduced-motion alternative.

## Start here

1. Define what the motion communicates and a usable reduced-motion or static state.
2. Choose the target platform and check the animation features against that specific player's support documentation.
3. Preview interaction, timing and the reduced-motion path in the actual target application.
