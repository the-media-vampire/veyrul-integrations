# Normalize spoken audio without guessing the delivery target

Start from a loudness target, measure the input and verify the encoded result. Keep noise cleanup and loudness adjustment separate.

## Start here

1. Record the destination's integrated loudness and true-peak requirements, channel layout and sample format.
2. Measure before processing. For a measured two-pass route, retain the first-pass values and the exact second-pass command.
3. Measure the final encoded output again; listen for clipping, pumping and other artifacts separately from numerical checks.

## Limits

The current saved overview covers measurement and tool selection. It is not a universal ready-to-run normalization recipe. Delivery targets and acceptable sound depend on the destination and material.
