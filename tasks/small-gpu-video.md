# Check whether a video workflow fits your GPU

Separate model-card hardware claims from offloaded template behavior before downloading weights or promising a memory fit.

## Start here

1. State GPU memory, system RAM, operating system, desired resolution and frame count.
2. Match the exact model variant, precision and offloading route to its source. Do not transfer figures between a native implementation and a ComfyUI template.
3. Only call a configuration tested after measuring that configuration's peak memory and completion on the target machine.

The saved comparison is documentary and does not establish that an arbitrary 8 GB or 12 GB GPU can run the chosen route. Download size, RAM and runtime remain separate constraints.
