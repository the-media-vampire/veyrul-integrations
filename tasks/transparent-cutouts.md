# Choose a cutout mode for hair, fabric and product edges

Compare alpha-only assembly, edge color correction and matting before promising that original RGB values will be preserved.

## Start here

1. Decide whether the deliverable needs transparency, corrected edge colors or both. These are different operations.
2. Pin the rembg version, model and local backend. Check the model's terms separately from the software license and account for first-use downloads.
3. Inspect edges on several backgrounds and compare decoded RGB where preservation matters. Keep the original image.
