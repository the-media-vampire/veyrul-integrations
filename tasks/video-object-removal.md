# Plan masked video editing with a VACE workflow

Find the documented input, mask and frame constraints before attempting object removal or another regional video edit.

## Start here

1. Read the specific template and model version together. Confirm mask meaning, dimensions, frame count and conditioning inputs.
2. Use a short authorized clip with an explicit region and acceptance criteria for motion, background reconstruction and protected details.
3. Inspect frames and playback around the mask boundary, then record actual settings, runtime and failed attempts.
