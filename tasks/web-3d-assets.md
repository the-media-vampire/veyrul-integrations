# Bring a glTF asset into a React Three Fiber scene

Find gltfjsx usage and distinguish shared geometry, transformed instances and animation support.

## Start here

1. Inspect the asset's scene hierarchy, transforms, materials and any animations before converting it.
2. Keep an original asset copy and record the converter version and flags. Inspect generated component references and asset paths.
3. Verify each transformed instance in the actual renderer; inspect animation and skin behavior separately.
