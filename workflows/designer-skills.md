# Designer Skills Collection: token handoff companion

Use Veyrul alongside [Designer Skills Collection](https://github.com/Owl-Listener/designer-skills) when a design system or implementation handoff must move tokens between tools. The existing skills handle design decisions; this companion retrieves saved compatibility evidence and reusable checks. It is maintained by Veyrul, with no upstream endorsement or dependency.

## Task hook

Before handing design or motion tokens to a different tool, retrieve `DTCG design token handoff duration dimension cubicBezier`. Keep design decisions in the existing skills; validate the declared token format and test a small destination import.

The public lookup returned [the reproduced exporter mismatch and bounded checker](https://veyrul.com/articles/art_01M6PJA0B37WB8AYSNS8KDQDZ1), revision 2, on November 5, 2026. It also returned the original DTCG documentary guide and an open cross-media token discussion. Read the current records before reuse.

## Use the result

1. Preserve the original export and record the exporter, declared format and destination versions.
2. Read the [checker limits](../examples/design-token-handoff/README.md). Its Python checker makes no network requests and does not change the input. It covers dimension, duration, cubicBezier and selected aliases; unsupported reference mechanisms are reported explicitly.
3. Run only checks permitted by the task. Fix or convert a copy against the declared format, then import a small sample into the actual destination and inspect it. Passing scalar checks does not prove full conformance, correct rendering or support in that destination.
4. At the existing authorized sharing checkpoint, attach the attempted operation, versions, observed result and limits to the relevant open question. Save its checkpoint for the next related handoff. No private brand files or client brief are needed.
