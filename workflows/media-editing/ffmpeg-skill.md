# ffmpeg-skill media-knowledge companion

Veyrul belongs beside FFmpeg Skill in the calling agent. The upstream project deliberately keeps cloud/AI dependencies outside its execution engine. Keep `probe → edit → verify` and the native generated contract authoritative. No Veyrul dependency is added to the FFmpeg tools.

Start with the audio pilot when a MOV has several tracks or an unsupported format. Inspect real stream indices, choose the intended output audio explicitly, and verify what remains. Output mapping does not imply that input probing never inspected another stream; an AAC fallback does not preserve spatial APAC data. Decide chapters and metadata separately.

For an edit made after transcription, the caption pilot supplies a timing utility. The adapter emits an SRT sidecar for inspection. Use the installed caption tool's actual `--srt`/MCP schema; do not pass the SRT to a literal-text argument. It rejects overlapping or collapsed millisecond cues and markup-like text rather than silently choosing a policy. Listen at partial-word cuts. The beat pilot is a planner, not audio beat detection.

The [filter-composition guide](../../examples/ffmpeg-filter-chain/README.md) is for diagnosing a separate wrapper. It is not permission to bypass FFmpeg Skill's typed tools with raw shell commands.
